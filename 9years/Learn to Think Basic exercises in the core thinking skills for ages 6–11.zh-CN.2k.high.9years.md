# 介绍

小朋友需要先学知识，才能动脑筋。  
你也要学会一些思考方法，用来思考学到的东西。  
试试看：想一想今天学到的新知识，可以问自己什么问题？

'Metacognition'（想想自己怎么想）就像一个思考工具箱，  
能帮你用不同工具来解决问题。  
试试看：想一想上次自己解决问题时，是怎么想的？

有些人以为我们能自然而然地学会这些思考方法，可研究发现并不是这样。  
我们经常用大约二十种“核心思考能力”（基本思考方法）来整理和理解信息，这些都写在目录里。  
试试看：试着数一数你今天用了几种思考小工具？

本书里的练习单能让你动手练习这些思考方法，  
并学会在思考时该问自己的问题。

本书里的思考方法分为四类：组织思考（分类信息）、分析思考（看出关系和模式）、评价思考（判断对错），以及创造性思考（想新点子）。  
试试看：选一类，想想每天何时会用到它？

练习内容包括数学、语文、社会和科学。

每课开始都有**导学笔记**（本课第一页），老师可以和同学一起讨论。

这一页还有一个示例，老师可以带着同学一起做，  
说明接下来练习题想要什么答案。

当你明白了方法，就可以做复印好的**学生**练习单上的题目。  
然后本书还会提供一些**建议答案**。

最后，大多数练习后面会有一些有用的问题，帮助你在思考时自问。  
老师可以让同学把这些问题写在自己的练习单上。

这些处理问题的小清单就像思考程序（小程序）一样，  
能帮你进行比较、分类、区分事实和观点、概括等等。

这本书有足够的练习，可以当成6～11岁小朋友的思考能力培养课程。

  
John Langrehr

# 观察事物的特点

* 我们身边不管是人做的东西，还是大自然的东西，都有它的设计（样子和构造）。每个设计都有它特别的理由，就像你挑生日蛋糕的样子一定是因为喜欢那个样子或味道。试试看：找一样你喜欢的东西，想想它为什么长这样。

* 我们说每个东西的设计（样子和结构）都有特定的用途（功能）。我们天天看很多东西，却很少问自己它为什么会这样做，就像看到滑梯，你会想为什么滑梯弯弯的而不是直的吗？试试看：选择一个你常用的东西，想想它是为了什么用才做成这样的。

* 第1课教你用更仔细或更用心的眼光看事物。当你看着身边的世界并动动脑筋，生活会变得更有趣，就像观察小蚂蚁搬食物会发现它们的本领。试试看：找一个小东西，用心观察它3分钟，记下你发现的细节。

* 为了帮助你关注你正在观察事物的特点

# 比较

# 分清事实和观点

* 当你读报纸或杂志时，你相信每一句话都是事实吗？  
  试试看：找一句你觉得很有趣的句子，想想它是事实还是观点。

* 如果不是，你怎么知道哪些句子是**事实**，哪些是**观点**？  
  试试看：用放大镜（想得更细）检查一下，决定它们是哪种类型。

* 本课帮你学会一些有用的问题，像有经验的思考者一样，把事实和观点区分开。  
  试试看：对一段简单的文字提三个问题，看看能不能找出观点和事实。

* 在判断下面的陈述时，尝试写下你在做决定时问自己的问题。  
  试试看：写下至少一个问题，帮助你分辨观点或事实。

* 下面是一个有用的问题列表，下次想在阅读中区分事实和观点时可以问自己。

1. 这句话里有没有**could**、**may**、**might**、**possibly**、**predict**、**should**等词？（观点）  
   试试看：把这些词换成“可能”，看句子还像事实吗？

2. 这个句子能通过**实验**或**证据**来证明吗？如果能 –  
   就是事实；如果不能 – 就是观点。试试看：找一句话，想想能不能用实验来证明它。

3. 这句话是出自权威人士（受人尊敬的人）的吗？(事实) 试试看：找一句新闻，看看它是谁说的。

4. 这句话里的事情是真实发生过，还是正在发生？(事实) 试试看：想一句话，想想里面的事有没有真的发生。

5. 这句话是和某人的感受（心里感觉）有关吗？(观点)&#x20;试试看：想一句话，看它是不是表达感受。

6. 这句话里有没有“是”、“有”、“曾经”或“做”这样的词？(事实) 试试看：找一句话，看看有没有这些词。

# 区分相关和不相关信息

相关信息就像拼图上的合适块，它们能帮你完成目标。  
比如，想选一辆新自行车，哪些因素相关？目标是买车。  
价格相关吗？是。买车的时间相关吗？不是。  
更多相关因素，决定就越好。  
首先，要想清楚你的目标是什么。  
然后，找出真正重要的因素，并想想原因。  
试试看：想想你最近买的一样东西，找出两条相关信息和两条不相关信息。

## 第 1 部分 为什么？还是怎么？提问器&#x20;

### **可能的答案**&#x20;

1\. 花朵。

* 花朵有很多种子。为什么？因为种子落地后不一定都能长出来，多一点机会更好。试试看：想想哪个种子最容易发芽？

* 花朵被叶子包围。为什么？因为叶子能吸收二氧化碳，为花朵提供营养。试试看：找一朵花，数数它有几片叶子？

* 花朵有时长刺。为什么？因为刺能保护花朵，不被动物吃掉。试试看：画一朵带刺的花。

* 花朵有很多颜色。为什么？颜色能吸引蜜蜂，把花粉带到其他花朵上，这样花就能结更多果实。试试看：找三种不同颜色的花，画下来。

2\. 鲸鱼。

* 鲸鱼是哺乳动物的例子。为什么？因为它们是温血动物，有脊椎，还生活宝宝。试试看：想想还有哪几种哺乳动物？

* 鲸鱼会长距离游泳迁徙。为什么？它们要去温暖海域生小鲸鱼。试试看：想象一下，画出鲸鱼的迁徙路线。

* 鲸鱼不是鱼。为什么？因为鲸鱼有肺，不是鳃。试试看：深吸一口气，想想鲸鱼怎么在水里呼吸。

* 鲸鱼常发出大声响。为什么？为了吸引其他鲸鱼一起游泳和交配。试试看：大声说“哈！”，想象鲸鱼吼叫的声音。

3. 阅读《昆虫》时的词语：**触角、翅膀、有害、卵&#x20;** 试试看：读一读这些词，想想它们的意思。

   1. 昆虫有两根长长的触角。为什么？昆虫用触角（感应器）感觉附近的东西和食物。试试看：闭上眼，想象自己在用触角找东西。

   2. 昆虫有两对翅膀。为什么？昆虫需要备用翅膀，以防弄坏时还能飞。试试看：用纸折一对翅膀，想象飞起来的感觉。

   3. 昆虫有时会有害。怎么有害？有些昆虫会吃庄稼、咬衣服、啃木头。试试看：找找生活里见过的昆虫，它们对我们友好吗？

   4. 昆虫会产千上万颗卵。为什么？因为捕食者会把卵当食物吃掉。试试看：在纸上画十颗卵，想象每一颗变成小虫。

* 一个办法是幻想或做梦，想出奇怪有趣的点子。试试看：闭上眼想象会发光的鞋子。

# 反向创意思维

* 创意思考的人常常试一种和大多数人完全相反的主意。

* 他们运用反向思考（就是反着想），这样可以打破你脑子里原本固定的思路。

* 你的大脑会记住你能拍下（能照相）或看得见的东西。要它想一些拍不出来（拍不了）的东西会比较难。就像你习惯把拼图拼成脸，就换成拼背景看看。这个课会帮你跳出大脑里的旧模式。 试试看：用反向思考想三个你见过的东西。

## **例子**

**问题**：列出三个找不到空气的地方。

**答案**：在外太空、灯泡里、真空中（没有空气的地方）、岩石内部。

# 分析设计中的创造力

* 有创造力的人像小侦探一样，能发现周围事物里的创造力。  
  试试看：变身小侦探，找一样家里常见的东西，想想它有什么特别的地方。

* 他们会注意人类和大自然创造的设计（就是外形和结构）。  
  试试看：观察一片树叶，想想它为什么要这样做？

* 我们周围的东西（狗、树、铅笔、汽车）都有各自的样子和用处。  
  试试看：拿起一支铅笔，想想为什么它是六边形的？

* 当你仔细观察，问自己为什么有特定的形状、颜色、大小、材质和硬度，你就能看到更多创造力。  
  试试看：找一个杯子，想想它为什么要用这种材料做成的？

* 你实际上在问第一个发明这些东西的人也会问的问题。  
  试试看：想想你最喜欢的玩具是谁发明的，他们一定也问过类似的问题。

## **示例：**

**问题：**
为什么瓶子是玻璃做的，而不是其他材料？第一个造瓶子的人一定想过这个问题。

**可能的答案：**
玻璃容易清洗，玻璃透明可以轻松看到里面的东西，玻璃熔点低，所以可以吹成瓶子的形状。

**问题：**
为什么网球是圆的？

**可能的答案：**
这样它可以更容易地滚动。

**问题：**
为什么网球又软又中空？

**可能的答案：**
这样它更轻，球员打起来更容易（又不容易受伤）。

## **可能的答案**&#x20;

1\. 铅笔通常为什么有六个面，而不是三个或十个？

更好握住，不易滚动，也好放进盒子里。试试看：你能拿三棱形和六棱形铅笔比比手感吗？

2. 树为什么有上千片叶子，而不是四五片？

叶子就像树的嘴巴和鼻子（呼吸小孔），用来吸收二氧化碳。试试看：用放大镜找找叶子上的小孔。

* 为什么报纸的页幅比书本的大？&#x20;
  报纸要做得很薄，才能不用装订，成本低，印刷便宜，丢弃也方便。试试看：把报纸对折，想想为什么书页不能这样做？

* 为什么杯子用陶土做而不是钢制的？&#x20;
  陶杯握起来不烫手，机器做也简单，喝的热量不容易散掉。试试看：拿个塑料杯和陶杯装热水，感受温度差别。

* 为什么狗和猫有四条腿，而不是两条或六条？&#x20;
  四条腿跑得快，两条腿拿不了东西，六条腿不好协调。试试看：用两条腿和四条腿跑步，哪个更稳？

* 为什么用红色来表示危险或提醒？红色是对眼睛刺激最大的颜色，能迅速吸引注意。试试看：看看你常见的红色警示标志有哪些？

* 为什么轮胎是用橡胶做的？

灵活柔软，让开车更舒适，制作和修补都容易，耐磨。试试看：找找家里不同轮胎的纹路，想想它们有什么作用？8. 为什么叉子有四个叉齿，而不是两个或十个？

四个叉齿能舀起食物，十个叉齿难清理缝隙，两个叉齿舀不了东西。试试看：用两叉和四叉分别捡豆子，哪个更顺手？

9. 为什么硬币通常是圆形的？

容易制造，没有锋利边缘，方便存放，也能轻松放进机器。试试看：收集几枚不同年份的硬币，试试看它们能否都放入存钱罐？

10. 为什么邮票通常是矩形的？

容易印刷，方便排版成整版，易撕下。试试看：试着把纸剪成小矩形，再体验一下撕标签的感觉。11. 为什么道路标志通常是白字绿底或黄字黑底？

  
白底绿字和黑底黄字对比度最高，最容易被人发现。**试试看：贴不同颜色的纸条，看看哪种最醒目。**

12. 为什么鱼有鳞片？

鳞片像小外套，让鱼暖和、游得更快，也不容易被人抓住。**试试看：摸一摸鱼鳞玩具，感受它有多光滑。**

13. 为什么硬币常常用铜做？

铜不会生锈，也能和其他金属混在一起（合成更坚固的合金），而且不容易弯曲。**试试看：拿一枚硬币，想想为什么它不容易弯曲。**

# 视觉创意

我们的大脑会记住常见的形状（外形）和它们代表的东西。看到别人跳出固定模式（不变化），我们也能学会灵活思考（不死板）。试试看：画两个不同的形状，写下它们能代表什么。

下面的五分钟练习会给你得分。试试看：想想你最多能写出多少不同的答案？

得分范围：  
**0-3** 个想法的类别 表示 灵活度低（死板）  
**4-7** 个想法的类别 表示 一般灵活度（不死板）  
**8+** 个想法的类别 表示 高灵活度（不死板）示例。试试看：你能想出 8 种不同的解释吗？
