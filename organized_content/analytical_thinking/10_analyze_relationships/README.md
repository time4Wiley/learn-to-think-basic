# 分析关系

## 内容预览

* 把概念放在一起是思考的基础（第1-9课）。拆分概念（**分析**）同样重要。当面对原始数据或信息时，我们要把它分解（**分析**）。试试看：选一样身边的物品，试着把它拆成若干部分。
* 这个练习里的问题常见于智力测验。试试看：自己想出一个类似的问题。
* 善于思考的人能像拼图游戏那样，先看每块小拼图（小事物），再拼成完整大图（大事物），快速分析它们的关系。试试看：想想拼图游戏中一块拼图和整体画面的关系。
