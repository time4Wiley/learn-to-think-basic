# 1. 观察特征

**页码:** 5

**所属部分:** 组织性思维（整理信息）

## 📝 本章概述

第1课教你用更仔细或更用心的眼光看事物。当你看着身边的世界并动动脑筋，生活会变得更有趣。

## 🔍 学习要点

### SCUMPS 观察法

记住缩写 **SCUMPS**，每个字母都帮你问自己：为什么它有这样的特征，而不是其他可能？

- **S** - Size (大小): 为什么是这个大小？
- **C** - Colour (颜色): 为什么是这个颜色？
- **U** - Use (用途): 为什么有这个用途？
- **M** - Material (材料): 为什么用这种材料？
- **P** - Parts (部件): 为什么有这些部件？
- **S** - Shape (形状): 为什么是这个形状？

### 观察示例

| 物品 | 属性 | 具备属性的原因/用意 |
|------|------|-------------------|
| 砖块 | 表面粗糙 | 水泥可以轻松的粘到砖块表面 |
|      | 比较沉 | 风不容易吹走 |
|      | 形状是长方体 | 容易摞起来 |

## 🎯 练习活动

### 试试看：

1. 找一样你喜欢的东西，想想它为什么长这样
2. 选择一个你常用的东西，想想它是为了什么用才做成这样的
3. 找一个小东西，用心观察它3分钟，记下你发现的细节
4. 选一样东西，用 SCUMPS 问自己每个问题

## 💭 思考问题

观察时可以问自己的好问题：

- 这个东西有什么大小、颜色、用途、材料、部件和形状（SCUMPS）？
- 为什么它要有这样的大小、颜色、用途、材料、部件和形状，而不是别的？

## 📚 扩展学习

- 和家人一起观察家里的物品，讨论它们的设计原因
- 在外出时，观察建筑物、车辆等的特征
- 画出你观察到的物品，并标注其特征
