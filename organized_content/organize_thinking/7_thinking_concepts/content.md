# 思考概念

* 我们来想想，大脑里怎么产生**想法**（头脑里的点子）或**概念**（共同特征）。就像搭积木。先看一个简单例子。试试看：想想你最喜欢的玩具有什么共同特征？
* 水果有什么特点（与众不同的性质）？
* 答案：带皮、长在树上、有种子、有果汁、甜甜的、有颜色、我们吃它。
* 有没有不符合这些特点的水果？我们把它们删掉。柠檬不甜，菠萝或葡萄不都长在树上，有的葡萄没籽。
* 剩下的特点都是**所有**水果共有的。我们把它们叫做我们的**概念**（共同特征）。试试看：写出另一种食物的共同特点。
* 如果要向火星人（外星人）描述水果，这些特点都适用。
* 下面是另一个**概念**的小例子。

## 示例

| 事物  | 特征                                                        |
| ------ | ----------------------------------------------------------------- |
| 一只鸟 | 巢（鸟窝）、会下蛋、两条腿、羽毛、尾巴、唧唧叫、头部、没牙齿 |

## 学生练习单

* 记录每个事物的三个或更多特征。

* 和同学一起，为每个事物列出很多事实。

* 然后划掉那些不适用于所有例子（事物）的事实。

* 剩下的特征就是你的**概念**（共同特征）。

## 可能的答案

| 事物     | 特征                                                                                     |
| --------- | ---------------------------------------------------------------------------------------------- |
| 硬币    | 圆形、金属、日期、国家、正面图案、面值                                           |
| 邮票   | 长方形、锯齿边、日期、国家、价格、背面有粘性                                     |
| 汽车     | 车轮、发动机、轮胎、方向盘、刹车、油箱                                         |
| 正方形  | 四条相等的直边、四个角、一个面积、封闭图形、对角线                         |
| 诗歌    | 文字、声音、意义、“意象”、可以写                                              |
| 行星  | 轨道、围绕太阳转、有大气层、圆形、在太空、反射阳光、自转 |
| 水果     | 果皮、果汁、有颜色、可以吃                                                             |
| 花朵  | 花瓣、颜色、叶子、香味、花蜜、雄蕊、吸引蜜蜂、花粉                         |
| 游戏    | 规则、玩家、胜利者、分数、结束、乐趣                                             |
| 文化 | 一群人的生活方式、有特殊的宗教、食物、服饰、习俗                        |
| 树木     | 树枝、树根、树干、树叶、树液                                                            |
