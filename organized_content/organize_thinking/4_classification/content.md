# 分类（归类相似）（试试看：把三样玩具分两类，说说它们的相同点）

* 我们会把相似的东西放在一起，存在大脑里。就像把玩具装进不同的盒子里。

* 在大脑的“文件柜”里，我们贴标签，比如“红色的东西”、“活的东西”、“大动物”等。

通过分类，当我们需要想例子时，就能快速想到。

* 观察越多、比较得越仔细，就能在大脑里存更多例子。

  
在这一课里，我们来看看你在大脑里的档案柜里，用了哪些标签来分类东西。就像你给积木分颜色、形状那样。你会发现自己的分类方法是什么。试试看：想一想，你用过哪些标签给玩具分类？

## 可能的答案

| 东西                        | 相同，因为它们都是...  |
| ----------------------------- | ----------------------------- |
| 剪刀、磁铁、钉子             | 用金属做的或机器做的          |
| 蚂蚁、甲虫、蝴蝶             | 昆虫                       |
| 冰、雾、蒸汽                 | 水做的                     |
| 煤、阳光、铀                 | 用来发电                   |
| 杠杆、斜面、滑轮             | 让你省力的工具              |
| 棉、羊毛、麻                 | 天然纤维                   |
| 照片、书页、门               | 长方形，人造的                |
| 轮胎、硬币、球               | 圆形                       |
| 软木塞、冰山、苹果           | 能漂在水面上                 |
| 数字7、11、13              | 奇数或质数（只能被1和自身整除）     |
| 三角形、正方形、多边形       | 多边形，几何图形            |
| 单词 walk、catch、climb      | 动词                       |
| 植物、动物、昆虫             | 有生命的东西               |

### 给东西分类时可以问自己的问题

* 这些东西的大小、颜色、用途、材料、部件、形状或其他地方相似吗？ 试试看：找三样东西，写下它们的相同点。
