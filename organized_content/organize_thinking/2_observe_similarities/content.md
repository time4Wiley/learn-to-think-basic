# 观察相似点

* 你想过两个或更多东西有什么相同之处吗？

* 比如，你吃过柠檬和香蕉吗？有没有想过这两种水果有什么相似的地方？

* 我们能想出至少四点，它们哪里相似吗？ 试试看：找两种水果，写出三条相似点！


还记得第一课的 SCUMPS 这个词吗？这些水果的大小、颜色、用途、材料、部件或形状（SCUMPS）有没有相同的？

**示例**

| 事物           | 相似特征                       |
| ---------------- | ---------------------------------------- |
| 香蕉&#xA;柠檬 | 都：黄色 食物 厚皮 在树上生长 |

## 可能的答案

| 事物             | 3个相似特征                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------ |
| 花朵和鸟           | 有生命，需要阳光、空气和水，不同种类和颜色。试试看：想想你认识的花和鸟，它们还有哪些相同点？      |
|                    |                                                                                                  |
| 道路和河流         | 都有名字，可以运送东西，都有起点和终点。就像小路和小溪，流向远方。试试看：找一条路和一条河，说说它们的三个相同点。 |
|                    |                                                                                                  |
| 椅子和马           | 都可以坐在上面，有四条腿，不同高度和颜色。想象一把椅子和一匹小马。试试看：找一张椅子和一匹马，说说它们的三个共同点。 |
|                    |                                                                                                  |
| 门和书             | 都是人做的，通常是长方形，用木头或纸做的，可以打开。就像书的封面和房门。试试看：观察你附近的门和书，列出它们的三个相似点。 |
|                    |                                                                                                  |
| 数字4和9           | 都是单个数字，都有确切的平方根（一个数×自己），都能整除36。想想4×4=16和9×9=81。试试看：写下4和9的平方根，并说明它们的相同之处。 |
|                    |                                                                                                  |
| 单词 fell、ran     | 都是动词（表示动作），只有一个元音，是过去式，没有大写。发音模式是辅音-元音-辅音（如 b-e-d）。试试看：写下两个其他过去式动词，说说它们和 fell、ran 有哪些相同点。 |
|                    |                                                                                                  |
| 正方形和圆形       | 都是封闭的平面图形（只有长和宽），是几何形状。就像饼干和饼。试试看：在纸上画一个正方形和一个圆形，找出它们的三个相似点。 |
|                    |                                                                                                  |

### 观察相似性时可以问自己的有用问题

  
* 这些东西有什么大小、颜色、用途、材料、部件和形状（SCUMPS）？  
* 这些东西的大小、颜色、用途、材料、部件和形状都一样吗？ 试试看：找出两件事物在 SCUMPS 上的不同点。
