# 观察差异

观察事物的不同点也很有用。比如，猫和狗都有生命、都是动物、都有四条腿，也都吃肉。但是，只有猫会喵喵叫或爬树。下次如果野狗追你，这个知识就派上用场了！本课检查你有没有注意并记录事物的小不同。试试看：想想猫和狗还有哪些不同，写下来。  

示例

| 事物 | 3个不同特征                          |
| ------ | ----------------------------------------------- |
| 猫和狗 | 只有猫可以：- 爬树 - 喵喵叫 - 捉老鼠 |
|        |                                                 |
|        |                                                 |

## 可能的答案

| 事物                     | 3 种不同的特点                                                           |
| -------------------------- | -------------------------------------------------------------------------------- |
| 椅子和桌子            | 椅子是给人坐的，每人一个，可以有软垫                         |
|                            |                                                                                  |
| 螃蟹和鱼              | 螃蟹有钳子、壳硬、会往后游、能离水生活              |
|                            |                                                                                  |
| 圆和三角形        | 圆没有直边、角或顶点                               |
| 数字4和11           | 4是偶数，不是质数，只有一位数                                    |
| 报纸和书         | 报纸便宜、每天出版、有很多作者、内容是最新新闻                         |
| 动脉和静脉            | 动脉壁厚、把血从心脏送出，数量较少                |
| 民主和独裁 | 领导人由人民选举、有言论自由、人民可以自由出国 |
| 总统和女王        | 政府领导人、通过选举产生、可以是男性              |
| 鸟和蜜蜂               | 鸟有两条腿、有血液、有骨头、寿命更长                                    |
