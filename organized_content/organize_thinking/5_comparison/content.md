# 比较

* 我们已经学过相同（第2课）和不同（第3课）。它们可以一起考虑吗？ 试试看：找两样东西，说说它们的相同和不同。

* 是的。可以同时想它们哪里不一样和哪里一样。 试试看：对比两种你喜欢的水果，说出它们的相同和不同。

* 你也可以想想它们的大小、颜色、用途、材料、部件和形状（SCUMPS）来帮助比较。 试试看：拿一本书和一个玩具，写出它们的相同点和不同点。

## 示例

| 只有鲨鱼（不同点） | 鲨鱼和猫都（相同点） | 只有猫（不同点）     |
| ------------------------- | ----------------------------------- | --------------------------- |
| 会游泳，没有腿，有鳃     | 吃肉，有血，有尾巴                | 喵叫，会爬树，被养在家里      |
|                           |                                     |                             |
|                           |                                     |                             |
