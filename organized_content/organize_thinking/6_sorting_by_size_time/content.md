# 按大小和时间排序

## 按大小排序

我们在脑子里也能把东西排成顺序。比如按大小、速度、花费来比较和排列。试试看：把三件玩具按大小排个队。

排序和比较东西，能让我们的记忆像一串珠子一样连接起来。

### 例子

| 乱序的东西          | 从大到小排序           |
| ----------------------- | -------------------------- |
| 森林,树枝,树,小枝 | 森林,树,树枝,小枝 |

#### 按大小排序时，可问的好问题

* 哪件东西包含所有其他东西？（最大）

* 哪件东西是所有其他东西的一部分？（最小）

* 哪件东西是第二大的？（包含除了最大以外的其他东西）。试试看：找三个玩具，按大小从小到大排一排。

## 按时间排序

* 就像刚才，我们会按大小把东西排好，不需要别人告诉我们。

* 我们还能按时间来排，就是按照事情发生的顺序。

* 下面的例子说明了按时间顺序（时间）的排序方式。试试看：把你一天的活动按先后写下来。

### 例子

| 打乱的东西                   | 按先后出现的顺序                   |
| ---------------------------- | -------------------------------- |
| 茧、毛毛虫、蛋、蝴蝶         | 蛋、毛毛虫、茧、蝴蝶              |

#### 按时间顺序排列时，你可以问自己的有用问题

* 什么事情要先发生，其他事情才能接着发生？就像做三明治，先涂酱再放菜。

* 什么事情在所有其他事情发生后才会发生？就像吃完三明治后才洗盘子。试试看：列出你做早操时的三个动作，并按顺序写下来。
