# 挑战主张的可信度

## 内容预览

我们经常在报纸上看到有人说自己看到了不明飞行物（UFO，未知飞行器）或怪物，比如大脚怪或尼斯湖水怪。你第一反应是问：‘这份报纸可信吗？’或‘写文章的人可靠吗？’我们自然想要一些证据（证明）才能相信他们，就像你听小伙伴说他看到海里有大鱼，你也想知道是真是假。试试看：想一想，你听到的一个故事，需要什么样的证据才能相信它。
一个会问问题的小侦探（找真相的人）会想一些有用的问题，让说主张的人回答，就像侦探问线索找真相。现在轮到你了，想想你会问什么来判断一个主张是否可信。试试看：写下三个问题，来考考别人说的话是真是假。
