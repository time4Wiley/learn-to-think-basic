# 提问让思考更好（试试看：想三个新问题）

* 大多数人在和别人聊天时，很难主动提问。

* 大多数学生等着回答问题，而不是自己提问。但是**你自己问的问题越多**，理解就越深。

* 当你提问时，你会更专心，也会把新知识和已知联系起来。

* **你提的问题越好，思考也越好**，尤其是批判性思考（分析能力）。

七个基本提问词（试试看：用‘为什么’和‘怎么’写两个问题）：

怎么？例如：电视怎样影响公众看法？

&#x20;为什么？比如：人们为什么会说谎？就像小侦探想真相，试试看：想一个“为什么”问题。&#x20;

&#x20;什么？比如：是什么原因让人生病？—— 试试看：想一个“什么”问题。&#x20;

&#x20;哪里？比如：我在哪里可以找到信息？—— 试试看：想一个“哪里”问题。&#x20;

什么时候？比如：什么时候做计划最好？哪一个？比如：哪个选择最合适？—— 试试看：想一个“什么时候”或“哪一个”问题。&#x20;

谁？比如：我可以相信谁？—— 试试看：想一个“谁”问题。

## **第二部分** 两个词开头的问题

### 学生练习单

这是一种自己造问题的另一种方法。—— 试试看：试用两个词造一个问题。

1. 从 A 行里选第一个词，就像做菜先挑主料。试试看：用 A 行的“什么”造一个问句。

2. 从 B 行里选第二个词，就像加好调料。试试看：用 B 行的“会”造一个新问题。

| A. | 什么 | 在哪里 | 什么时候 | 哪个 | 谁 | 为什么 | 怎么 |
| -- | ---- | ------ | -------- | ---- | -- | ------ | ---- |
| B. | 是/在/做/做了吗/曾是 | 会/能/可以 | 可能 |       |     |     |     |

3. 现在用这两个词造一句完整的问题，就像搭积木拼城堡。试试看：把刚才选的两个词，组成一个有趣的问句。

***

示例主题：云朵

| 什么    | 云朵由什么组成？             |
| ----------- | --------------------------- |
| 为什么     | 云朵形状不同是为什么？ |
| 谁会       | 谁会对云朵感兴趣？    |
| 在哪里可能 | 在哪里看不到云朵？    |
| 怎么    | 云朵是怎么形成的？                |

你可以用 A 行和 B 行的词，造出 30 个或更多有趣又不同的云朵问题，想象你大脑里冒出好多新连接！试试看：写出五个关于云朵的问题。

## 第 1 部分 为什么？还是怎么？提问器&#x20;

### **可能的答案**&#x20;

1\. 花朵。

* 花朵有很多种子。为什么？因为种子落地后不一定都能长出来，多一点机会更好。试试看：想想哪个种子最容易发芽？

* 花朵被叶子包围。为什么？因为叶子能吸收二氧化碳，为花朵提供营养。试试看：找一朵花，数数它有几片叶子？

* 花朵有时长刺。为什么？因为刺能保护花朵，不被动物吃掉。试试看：画一朵带刺的花。

* 花朵有很多颜色。为什么？颜色能吸引蜜蜂，把花粉带到其他花朵上，这样花就能结更多果实。试试看：找三种不同颜色的花，画下来。

2\. 鲸鱼。

* 鲸鱼是哺乳动物的例子。为什么？因为它们是温血动物，有脊椎，还生活宝宝。试试看：想想还有哪几种哺乳动物？

* 鲸鱼会长距离游泳迁徙。为什么？它们要去温暖海域生小鲸鱼。试试看：想象一下，画出鲸鱼的迁徙路线。

* 鲸鱼不是鱼。为什么？因为鲸鱼有肺，不是鳃。试试看：深吸一口气，想想鲸鱼怎么在水里呼吸。

* 鲸鱼常发出大声响。为什么？为了吸引其他鲸鱼一起游泳和交配。试试看：大声说“哈！”，想象鲸鱼吼叫的声音。

3. 阅读《昆虫》时的词语：**触角、翅膀、有害、卵&#x20;** 试试看：读一读这些词，想想它们的意思。

   1. 昆虫有两根长长的触角。为什么？昆虫用触角（感应器）感觉附近的东西和食物。试试看：闭上眼，想象自己在用触角找东西。

   2. 昆虫有两对翅膀。为什么？昆虫需要备用翅膀，以防弄坏时还能飞。试试看：用纸折一对翅膀，想象飞起来的感觉。

   3. 昆虫有时会有害。怎么有害？有些昆虫会吃庄稼、咬衣服、啃木头。试试看：找找生活里见过的昆虫，它们对我们友好吗？

   4. 昆虫会产千上万颗卵。为什么？因为捕食者会把卵当食物吃掉。试试看：在纸上画十颗卵，想象每一颗变成小虫。
